# C964 - Computer Science Capstone
# Design and Development

#### I. Design and develop your fully functional data product that addresses your identified business problem or organizational need from part (A). Include each of the following attributes, as they are the minimum required elements for the product: <br>

<ul>  
  <li> One descriptive method and one nondescriptive (predictive or prescriptive) method
  <li> Collected or available datasets
  <li> Decision support functionality
  <li> Ability to support featurizing, parsing, cleaning, and wrangling datasets
  <li> Methods and algorithms supporting data exploration and preparation
  <li> Data visualization functionalities for data exploration and inspection
  <li> Implementation of interactive queries
  <li> Implementation of machine-learning methods and algorithms
  <li> Functionalities to evaluate the accuracy of the data product
  <li> Industry-appropriate security features
  <li> Tools to monitor and maintain the product
  <li> A user-friendly, functional dashboard that includes three visualization types
</ul>

#### II. Create each of the following forms of documentation for the product you have developed:

<ul>
  <li> A business vision or business requirements document
  <li> Raw and cleaned datasets with the code and executable files used to scrape and clean data (if applicable)
  <li> Code used to perform the analysis of the data and construct a descriptive, predictive, or prescriptive data product
  <li> Assessment of the hypotheses for acceptance or rejection
  <li> Visualizations and elements of effective storytelling supporting the data exploration and preparation, data analysis, and data summary, 
    including the phenomenon and its detection
  <li> Assessment of the product’s accuracy
  <li> The results from the data product testing, revisions, and optimization based on the provided plans, including screenshots
  <li> Source code and executable file(s)
  <li> A quick-start guide summarizing the steps necessary to install and use the product
</ul>
